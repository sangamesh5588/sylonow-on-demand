# ⚡ SyloNow On-Demand — Real-Time Service Dispatch & Fulfillment Gateway

[![React](https://img.shields.io/badge/React-18.x-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://react.dev)

[![Supabase](https://img.shields.io/badge/Backend-Supabase-3ECF8E?style=for-the-badge&logo=supabase&logoColor=white)](https://supabase.com)

> **SyloNow On-Demand** manages the real-time fulfillment lifecycle for same-day and scheduled celebration services. It matches incoming customer requests with nearby available vendors and coordinates status updates.

---

## ✨ Features

- ⏱️ **Real-Time Job Dispatch:** Dynamic assignment of incoming event orders to certified service partners.
- 🔄 **Live Status Synchronization:** Real-time state transitions powered by Supabase WebSockets.
- 📍 **Service Radius Filtering:** Assigns jobs based on proximity to the customer event location.

---

## 🚀 Quick Start
```bash
git clone https://github.com/sangamesh5588/sylonow-on-demand.git
cd sylonow-on-demand
npm install
npm run dev
```
